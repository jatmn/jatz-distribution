# Roads

Freighters drive only on road tiles. The road tile, `jatz-road`, uses the slag path artwork from **Yuoki Industries - Railways**.

## Third-party artwork

Everything in `yuoki-railways/` is copied unchanged from [Yuoki-Railways-Factorio-2.0](https://github.com/jatmn/Yuoki-Railways-Factorio-2.0/tree/7ae42338cad134849135b56ab98f404417e1d73a/graphics/path_tiles), commit `7ae42338cad134849135b56ab98f404417e1d73a`, `graphics/path_tiles/`.

| --- | --- |
| `slag1.png` | Sixteen 1×1 road variants, 32 px per tile |
| `slag2.png` | Four 2×2 variants |
| `slag4.png` | Four 4×4 variants |

The game mixes the 1×1, 2×2 and 4×4 variants so long roads don't visibly repeat.
