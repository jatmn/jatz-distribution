  Features:
    - Added the startup setting "Liquid request depot tank size" (25,000 by default), like the liquid provider and liquid buffer ones. A liquid request depot's freighters only set off for what still fits in its tank, counting what is already on its way, so a bigger tank lets more of them out at once. A request set in an older version keeps the amount it was capped to: type it again once after making the tank bigger.
    - Added "Use freighter storage" to liquid request and liquid buffer depots (off by default). Ticked, a depot can hold, and request, as much as all its freighters carry when that is more than its tank. Fluid the tank has no room for stays in the parked freighters and goes into the tank as soon as there is room. A liquid depot's request now keeps the amount you typed and asks for as much of it as the depot can hold, so it follows the limit.
