# Security policy

Please report suspected vulnerabilities privately through [GitHub's Report a vulnerability form](https://github.com/jatmn/jatz-distribution/security/advisories/new). Do not put credentials, private logs, or exploit details in public issues or pull requests.

Include the affected commit or version, reproduction steps, expected and actual behavior, and the likely impact. Redact secrets and personal paths from attachments. If a credential was exposed, revoke or rotate it; deleting a file does not remove it from Git history or existing downloads.

The project is in development. Security fixes target the current `main` branch; older development snapshots do not receive separate backports. Reports about the mod, development tools, dependencies, or GitHub Actions are welcome. Response times depend on maintainer availability.

The installed mod contains Lua and game assets. Python packages and Blender are development dependencies. See [NOTICE](NOTICE) for the separate licences of third-party assets.
